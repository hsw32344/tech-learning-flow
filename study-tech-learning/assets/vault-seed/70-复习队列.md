# 技术学习复习队列

## 使用规则

- 本文件只保存从实际学习和复习记录推导出的执行队列，不是学习事实或能力证明。
- 事实仍写在学习日志、工作日志和各复习题的 `## 复习记录`；只有实际练习、复习或验收结果才能由 `record-tech-learning` 推进本队列。
- `study-tech-learning` 不读取、创建、激活或推进本队列；普通学习日程不自动加入复习。
- `direct-tech-learning` 只在用户明确要求练习、复习或验收时交接相关目标；不按日、周或日历安排复习。
- 可用验收层级为：因果预测 → 修错定位 → 换情境迁移 → 保持检验。层级只描述实际验收状态，不是课程推进门槛，也不写“已掌握”。
