# Vault 术语规范

## 作用范围

- 本规范适用于学习主线、首页、周记录、学习回顾、原子知识、主题地图、复习题、模板以及 Skill 的对话输出。
- 自然语言优先使用“规范名”；讨论代码符号或 API 时使用“代码写法”。

## 命名格式

- 学习主线阶段：`<技术范围>：<能力范围>`。
- 主题地图：使用一个已登记的主题名。
- 原子知识：`<规范名或代码写法> - <可检索的知识主题或操作>`。
- 复习题：`<规范名或代码写法> - <测试目标>复习`。

## 分类轴

- **结构角色**只说明条目在 Vault 中承担的组织位置：领域、阶段、任务包、主题、知识术语、标签或历史项。
- **知识类别**只说明知识术语的内容性质：概念、机制、语法角色、API 或实践模式；非知识术语必须留空。
- 不得把组织层级和知识性质混写在同一列。
