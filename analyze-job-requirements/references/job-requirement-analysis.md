# Job requirement analysis contract

## Evidence layers

Keep four layers separate:

1. **Source fact**: wording explicitly present in the supplied HR/JD material.
2. **Normalized mapping**: the closest canonical capability, mainline unit, tool, output, or gate.
3. **Inference**: a plausible implication that is not explicitly stated.
4. **Recommendation**: a proposed priority or route change.

Quote or closely preserve decisive source wording. Label inference and recommendation; never blend them into the source.

## Requirement classes

| Class | Meaning | Route effect |
|---|---|---|
| Hard gate | Degree, location, availability, language, years, eligibility | Report separately; no learning unit unless the user explicitly chooses a trainable component |
| Must-have | Explicit required capability or tool | Compare with the core route and named target-job priority |
| Preferred | 加分、优先、有经验更佳 | Keep behind core must-haves unless repeated or user-selected |
| Responsibility | Work the role is expected to perform | Map to business task, method, input data, and deliverable |
| Output/KPI | Report, dashboard, model, accuracy, speed, business result | Convert to an observable interview artifact; never claim achieved impact |
| Context | Industry, team, platform, scale, collaboration | Use to specialize examples and projects without making it universal |

## Mainline mapping statuses

- `covered-current`: already covered at or before the current core interview stage.
- `covered-later`: declared in the route but currently later.
- `reprioritize`: declared but should move earlier for the named target job.
- `candidate-new`: not adequately represented and potentially worth a new or expanded unit.
- `job-specific`: useful for this source but not justified as a general route change.
- `non-learning-gate`: hiring constraint rather than a technical learning item.
- `uncertain`: wording or source context is insufficient.

## Priority reasoning

Use this order:

1. explicit must-have for the named target job;
2. repeated must-have across distinct current sources;
3. responsibility needed to produce an explicit deliverable or KPI;
4. explicit preferred item;
5. inferred or generic wording.

Count distinct job sources, not repeated phrases inside one source. Do not attach a market-frequency percentage without a defined source set and denominator.

## Change handoff

For every suggested mainline effect, include:

- source note or source boundary;
- original phrase;
- normalized capability;
- current unit mapping or missing area;
- mapping status;
- target-job priority and general-route priority;
- prerequisites and displacement cost;
- observable interview artifact;
- confidence and unknowns;
- retained, moved, added, skipped, and job-specific treatment.

The handoff is a proposal, not an approved route write. `direct-tech-learning` remains the sole mainline writer.
